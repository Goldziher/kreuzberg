# Pdfium public headers

The `pdfium_7678/` headers are unmodified public C API headers from the official
[Pdfium Chromium 7678 branch](https://pdfium.googlesource.com/pdfium/+/refs/heads/chromium/7678/public/),
pinned to commit `efbbd0fc95825e049ad790911356e0b689418899`. They are the build inputs for the optional
`bindings` feature. `LICENSE.pdfium` is the upstream BSD license from the same commit.

`rust-import-wrapper.h` is generated by the build script and is not vendored.
